01 / About

Pipelines built around trustworthy data

My work centres on reliable ETL pipelines that turn raw data from multiple sources into validated, analytics-ready datasets, across the supply chain and banking domains. Today, at AsmaWebs for Halcyon Agri, I am building an end-to-end AWS data platform for global rubber supply chain data with Python, PySpark and SQL, using Glue, S3, Athena, Lambda and Step Functions, with star-schema data models and orchestrated, monitored workflows.

Vendor Data Integration & ETL Pipeline

  • 2.3M+Records ingested
  • 10,692Vendor-brand records
  • $451.6MSales tracked in dashboard
Problem
Purchase, sales, freight, vendor and brand data sat in 6 separate source datasets, including a 2.3M-row sales file.
Workflow
A Python, Pandas and SQLAlchemy pipeline ingests the 6 datasets into a relational database using chunked loading. SQL multi-table joins then combine them into one analytics-ready dataset of 10,692 vendor-brand records across 18 fields, with zero null values.
My contribution
Built the pipeline and the reusable Python and SQL logic for vendor performance and inventory metrics. Traced invalid profit margin values in 178 zero-sales records back to the transformation logic and corrected the rules. Applied cleansing, reconciliation and validation checks, and flagged 698 dead-stock outliers (6.5% of records), filtering them out of margin averages instead of deleting them.
Result
Feeds a Power BI dashboard that tracks $451.6M in sales, a 28.7% profit margin and $939.7K in unsold capital.
